# Phone Check product website

A standalone static product page in this repository, with the demo hosted on
YouTube. No hosting-provider SDK, backend, external fonts, or ChatGPT Sites
dependency.

## Build and preview

```sh
cd website
npm run build
npm run preview
```

Open http://127.0.0.1:4173. Node is needed only for the copy-based build;
Python 3 serves the local preview. No dependency install is needed for the site.
Publish the contents of `website/dist/` to any static host. Assets use relative
paths, so GitHub Pages project URLs and other subdirectory hosts work as well.

## GitHub Pages

[The Pages workflow](../.github/workflows/pages.yml) builds and deploys the site
automatically when website files change on `main`. It can also be run manually
from Actions. Only `website/dist/` is published; captures, video source, native
app code, and configuration files are excluded from the deployment. No package
installation or video rendering is needed in CI.

One-time setup after creating the GitHub repository:

1. In **Settings → Pages → Build and deployment**, select **GitHub Actions** as the source.
2. Push `main`, or run **Publish product website** from Actions if already pushed.

The neighboring `../kbd-mouse` repository belongs to `amanpalariya`. If this repo
is created there as `phone-check`, its default Pages URL will be
`https://amanpalariya.github.io/phone-check/`. The workflow uses the repository’s
actual Pages URL, so it also works with a different owner or repository name.
No GitHub remote is configured locally yet.

Public app distribution is not configured in the repository, so the page clearly
states that downloads are forthcoming. Replace that section with verified release
URLs when signed releases exist.

The layout is capped at 864px. The theme selector follows the system by default;
explicit Light and Dark choices persist locally. White and macOS-style neutral grays
form the page palette, with blue accents from the app icon.

## Product assets

- Android screenshot: production Compose screen in a synthetic connected state,
  captured on the API 37 emulator by `ProductCaptureTest`.
- Mac screenshots: production SwiftUI notification views in an isolated app with
  synthetic notifications, real Android app icons exported from installed Google Messages, Gmail, and YouTube Music packages, and no running sync
  services. Capture-only Focus access and connection state never affect release
  builds. The blurred editor backdrop is an actual VS Code screenshot of this website’s source on the Mac.
- The music sample is “Patient Zero” by Taylor Swift, checked against Apple Music and iTunes metadata on October 30, 2026. Artwork and track metadata sources are recorded in `assets/brands/music-source.json`.
- The sample media controls are notification controls. Audio from the displayed
  track and calls is not recorded. A separate quiet instrumental bed and softer pointer taps
  accompany the video; sources are in `video/public/audio/README.md`.
  The YouTube player starts muted, with playback, sound, and fullscreen controls
  placed below the video.
- All demo notifications and replies are synthetic. Transitions in the video
  illustrate behavior; this is not an end-to-end phone transport recording.
- Samsung Galaxy S26 framing uses an existing Hoverify device frame; its source is recorded in `assets/brands/README.md`.
- Raw captures in `assets/captures/` are retained separately from the optimized assets served by the site.

Build the Mac capture fixture:

```sh
./website/scripts/capture-mac.sh
```

The current motion fixture is a fixed 1600 × 900 point stage with the production
UI rendered at 2× layout scale. `scripts/record-native.swift` captures only that
window with ScreenCaptureKit. Run it with a `.mov` output path and send a newline
to finish. `scripts/prepare-native-clips.py <recording.mov>` trims the recorded
session into the clips used by the composition. The current timing markers and
source offsets are retained alongside the assets. See `video/README.md`.

The original gallery stills remain in `assets/captures/`; `prepare-assets.py`
exports their JPEG/WebP derivatives. The staged phone camera view uses the real
Google scanner UI with a synthetic QR feed and is generated by `stage-scanner.py`.

Android capture:

```sh
cd android
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5554 shell am instrument -w -e class dev.phonecheck.ProductCaptureTest dev.phonecheck.test/androidx.test.runner.AndroidJUnitRunner
adb -s emulator-5554 exec-out run-as dev.phonecheck cat files/product-android.png > ../website/assets/captures/android-connected.png
adb -s emulator-5554 exec-out run-as dev.phonecheck cat files/product-android-pairing.png > ../website/assets/captures/android-pairing.png
```

Use a disposable emulator. The fixture itself does not sign in, pair, or grant
notification/local-network access.

## Video

Editable Remotion source is in `video/`, separate from the dependency-free site.

```sh
cd website/video
npm ci
npm run dev -- --no-open
npx remotion render src/index.ts PhoneCheck ../public/assets/phone-check-demo.mp4 --codec h264 --crf 16
npx remotion still src/index.ts PhoneCheck ../public/assets/demo-poster.jpg --frame=570
cd ..
npm run build
```

Playback is muted and inline, pauses offscreen and in hidden tabs, and has a
keyboard-accessible play/pause control. Reduced-motion users see the poster until
they explicitly play. Static content and FAQ remain usable without JavaScript.

required.
